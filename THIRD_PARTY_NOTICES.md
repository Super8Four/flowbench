# Third-party software

Standalone DNS checks use dnspython 2.9.0 (ISC), without optional extras. The complete upstream notice is preserved at `app/third_party/licenses/dnspython-LICENSE.txt`. The Python >=3.11, pure-Python wheel from [PyPI](https://pypi.org/project/dnspython/2.9.0/) was checked against SHA-256 `9a4aedb833c3c1b49214d04d44d3032ab7a9135f7c1d29a549b4ff78fd82fda9`; source tag `v2.9.0` is published from commit `e790c8f20a67ad439c7aafef2321e161c6028eee`. Queries use only operator-selected targets and explicit or locally configured resolvers. No public resolver, DNS-over-HTTPS dependency, extra privileges, or external capability probe is added.

Optional offline IP geolocation uses maxminddb 3.2.0, the Apache-2.0-licensed MaxMind DB Python reader. Its complete upstream license is retained at `app/third_party/licenses/maxminddb-LICENSE.txt`; the reader supports a pure-Python memory-mapped implementation on Windows and Linux. This library reads local files and does not supply geolocation data.

The optional external [DB-IP IP to City Lite MMDB](https://db-ip.com/db/download/ip-to-city-lite) dataset is licensed under [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). It is not bundled in Git or the application image and is never downloaded automatically. Pages and unredacted reports displaying its results must retain the attribution [IP Geolocation by DB-IP](https://db-ip.com), its license and available dataset build date. Results are approximate network locations, with reduced coverage/accuracy; they are not device GPS positions or evidence that traffic physically followed a geographic line. Private and special-use addresses are not looked up or assigned coordinates. Data remains in the operator's persistent local data directory; the reader makes no external geolocation requests.

Report generation uses ReportLab 5.0.1 (BSD 3-clause) and python-docx 1.2.0 (MIT). Complete upstream notices are retained in `app/third_party/licenses/`, together with the Bitstream Vera font license. The PDF renderer embeds Vera and attaches its license to generated PDFs. Installed dependency distributions also retain their notices.

The optional Flent integration invokes an external Flent executable; Flent source is not copied into application code or the portable runtime image. Flent 2.3.0 is GPLv3, and its license excludes generated output. The test-only derivative installs Flent and preserves its distribution; its Netperf source is pinned to MIT-licensed commit `afc51ff9764741da4ed6702651fba9d9c23f8557` with the complete COPYING notice preserved. See [the integration and distribution boundary](docs/flent.md).

The bundled public server catalog in `app/data/public-servers.json` is derived from the parsed export at https://export.iperf3serverlist.net/listed_iperf3_servers.json, retrieved October 11, 2026 UTC. The source project is https://github.com/R0GGER/public-iperf3-servers and its website is https://iperf3serverlist.net/. Its MIT license notice is preserved in `app/data/LICENSE-public-iperf3-servers.txt`. Server locations, options, and capacities are catalog listings, not results from this application. Refreshing the list downloads data only.

The optional Windows installer downloads iPerf3 3.22 from the community build project https://github.com/ar51an/iperf3-win-builds/releases/tag/3.22 and verifies the published release asset SHA-256. Downloaded binaries are ignored by Git and are not part of this application's source distribution. iPerf3 is developed by ESnet under a BSD 3-Clause license: https://github.com/esnet/iperf/blob/master/LICENSE. Windows support comes from the community build.

The Ubuntu container builds ESnet's upstream iPerf3 3.22 source archive from https://downloads.es.net/pub/iperf/iperf-3.22.tar.gz after verifying the published SHA-256 `1c0d0fb02c52626111d6e132db80edfbf27bbaff8bd9245df2a371dcb0b35a92`. Its upstream license is installed at `/usr/local/share/licenses/iperf3/LICENSE` in the image. Compiler tools and source archives stay in the build stage. Ubuntu packages and Python dependencies retain their distributed license metadata.
