{% endmacro %} {% macro check_fields() %}
DNS lookup

Enter the full name to query. No public target or resolver is selected automatically. PTR accepts a numeric IP address.

Record type is independent of the resolver's IP family. A truncated UDP response may trigger one TCP fallback within the same query deadline. Total execution is bounded to 30 seconds, including clock and setup.

ICMP echo check

At most one echo probe per second, with a one-second reply timeout. A resolved IP is held fixed for the check. Total execution is bounded to 120 seconds. ICMP echo nonresponse does not prove application failure or packet loss for other traffic.
